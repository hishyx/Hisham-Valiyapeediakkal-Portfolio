# Hisham Valiyapeediakkal — Portfolio

A React 19 + TypeScript portfolio built with Vite, Tailwind CSS, Motion for React, and Lucide React. It is a frontend-only application with no backend or hosting-specific assumptions.

## Run locally

```sh
npm install
npm run dev
```

Create and verify a production build with:

```sh
npm run build
npm run preview
```

## Replace images

- Portrait: replace `public/images/hisham.jpg`, `public/images/hisham.webp`, and `public/images/hisham-480.webp` with optimized versions of the updated photograph. Keep those filenames; the hero selects WebP sizes responsively and falls back to JPEG.
- LogiaFun: replace `public/images/logiafun.webp` with a current project screenshot.
- Pillarthree Productions: replace `public/images/pillarthree_desktop.webp` with the desktop screenshot. `public/images/pillarthree_mobile.webp` is used on small screens.
- Responsive screenshot variants are `public/images/logiafun-960.webp` and `public/images/pillarthree-desktop-960.webp`.
- The User Management System uses a designed role and workflow visualization until a real screenshot is available.

Project copy, links, statuses, and technology lists are maintained in `src/data/projects.ts`. The Assignaura ecosystem graphic is an illustrative product vision, not a representation of completed features or private database details.
